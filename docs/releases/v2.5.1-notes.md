# v2.5.1 release notes

A security update to v2.5.0. Its full notes are in [v2.5-notes.md](v2.5-notes.md).

## Security

- **The built-in updater uses a fixed zip library.** tauri-plugin-updater 2.14.1 moves from zip 4 to zip 9, which clears RUSTSEC-2026-0367, 0368, 0369 and 0429 (GitHub alerts GHSA-m665-v7pm-7grj, GHSA-q7v9-x93c-xqv3 and GHSA-8hxf-qr8p-62x4). The app's own archive extraction was already on zip 9. Updates are minisign-verified before installing, and Windows updates are a signed NSIS installer rather than a zip, so nothing was known to be at risk.

## Other updates

- **Dialogs:** tauri-plugin-dialog 2.8.4 and rfd 0.17. The cloud-AI consent prompt still treats Esc, Enter and closing the window as "Don't send" (checked on Windows).
- **Single instance:** tauri-plugin-single-instance 2.5.5. Launching the app again while it's quitting now goes to the closing app instead of opening a second copy.

## Behind the scenes

- The release page gets the generated changelog once (it appeared four times on v2.4.0 and v2.5.0).
- The system evals check more: the Ask contract suite is required, Enhance has a pooled-padding forged-notes case, and the retrieval baselines hold today's scores.
